# Nut & Nectar — dry fruits ecommerce demo

Standalone responsive storefront. Open with a static HTTP server; no build step.

Features: eight sample products, categories, search, sort, product details, pack sizes, Buy now shortcuts, mobile checkout bar, basket with browser persistence, quantity controls, sample delivery calculation, validated demo checkout and downloadable order summary.

This is a demo only. Orders and customer addresses are not sent to a server, and no payments are taken. The basket stores only product IDs, weights and quantities. Customer fields are cleared after demo checkout. Product photographs are stored locally in assets/. Source links are listed in photo-credits.html.

For a production shop, configure merchant branding, actual catalogue and food information, stock, order storage and notifications, delivery coverage and rates, payment provider, and applicable policies.
